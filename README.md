# Ahso Studio Landing Page

Marketing site for Ahso Studio, a micro SaaS and AI web app partner for small and medium businesses. Built with Next.js 14, TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

## Features

- Hero section with clear value proposition and call-to-action
- Services overview with pricing tiers
- Process, unique selling points, and studio story sections
- Responsive design with Tailwind CSS and custom gradient styling
